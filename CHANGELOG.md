# Changelog

All notable changes to Hacker CLI Gym are recorded here.

## 2.0.0 - 2026-08-18

- Expanded the project to 500 Linux and 500 Windows PowerShell exercises.
- Replaced simulated Linux input with unrestricted commands in a hardened,
  disposable Debian container.
- Added outcome-based grading, progressive hints, blind capstones, daily queues,
  spaced review, mastery, XP, levels, and progress backup/recovery.
- Added a persistent PowerShell lesson runspace and a disposable Windows Sandbox
  launcher.
- Added open-ended sample files, profiles, resource limits, diagnostics, and
  prebuilt multi-architecture Linux image support.
- Hardened both runners against workspace links, progress tampering, malformed
  state, controller-state changes, and failed-command grading.
- Added reproducible curriculum generation and full reference-solution checks
  for both platforms.

## 1.0.0

- Initial Linux command-line gym.
