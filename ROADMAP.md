# Roadmap

Hacker CLI Gym is intentionally small, practical, and community-driven. Likely
next areas of work are:

- a PowerShell 7 track that replaces Windows PowerShell-only commands while
  preserving the existing Windows PowerShell 5.1 curriculum;
- more accessibility testing and terminal-friendly display options;
- community-contributed alternative fixtures and explanations;
- additional import/export tools for instructors and learners;
- published, versioned container releases for every stable release.

The project does not plan to add cloud accounts, telemetry, subscriptions, or a
hosted learning platform. Suggestions are welcome through GitHub issues.
